# Bach 硬件设计建模参考

从集群到 core 内部的完整设计说明，依据 `perfechpitch/Bach/` 下 40 篇设计文档整理，面向 latch 建模工程。

* 第 1 章是导览，建立整体图像
* 第 2 至 7 章按抽象层次从系统走到 core 内部，是各自领域的权威描述
* 第 8 章登记尚未确定的部分。**凡是它列出的取值都不要当作已定**

每章头部声明自己的模式：

* **design**：陈述当前设计，动机与取舍收在各节的“取舍”段落里
* **tutorial**：不定义规则

| [DTE 数据搬运引擎](04-dte-数据搬运引擎.md) | design | DTE 专题：一个搬运任务怎么被拆成读写两半又合回一次完成，三条数据流，一个包拆成哪四类内容、地址怎么算出来、五个搬运方向各自怎么配。第 4 章的展开。 |
